# FinMatch AI

## 프로젝트 소개
Java와 Spring Boot를 활용한 학생회 회계 장부 자동 대조 및 검토 시스템입니다.

## 개발 배경
학생회 재무 담당자가 영수증을 기반으로 작성한 Excel 지출 명부와 실제 은행 거래내역 사이에 누락 및 금액 입력 오류가 발생할 수 있다는 점에서 기획했습니다.

은행 거래내역을 기준으로 지출 명부를 대조하여 오류 의심 항목을 찾고, 담당자의 검토를 돕는 것을 목표로 합니다.

## 주요 기능 (구현 예정)
- 은행 입출금 Excel 파일 업로드
- 학생회 지출 명부 Excel 파일 업로드
- 은행 출금 거래 추출 및 이월 출금 구분
- 은행 행사 지출과 학생회 지출 명부 자동 비교
- 누락·중복·금액 불일치 의심 거래 검출
- 연도별 수입·지출 및 잔액 조회
- AI API를 활용한 회계 검토 보고서 생성

## 사용 예정 기술
- Java 21
- Spring Boot
- MySQL
- Apache POI
- HTML/CSS, JavaScript
- AI API

## 테스트 데이터
- 2022~2026년 가상 은행 거래내역 및 학생회 지출 명부
- 실제 개인정보 및 금융정보를 사용하지 않은 가상 데이터
- 금액 오입력, 누락, 중복 입력, 날짜 오입력, 거래처 표기 차이 등 테스트 사례 23건
- 검증용 정답은 지출 명부의 `TEST_ANSWER` 시트에 별도 보관
